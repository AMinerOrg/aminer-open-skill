# File formats

## Label files written by the agent

### `labels/stage1_NNN.json` (sentence types)

Three shapes are accepted and can be mixed; several files are merged automatically:

```jsonc
// recommended: a range plus the non-context sentences (unlisted ids inside the range = context)
{"range": [1, 40], "opinion": [3, 14, 16], "citation": [22, 23]}
// one label per sentence
{"1": "context", "3": "opinion", "22": "citation"}
// array form
[{"id": 3, "type": "opinion"}]
```

Types: `context | citation | opinion` (also accepted: background / cite / viewpoint and the Chinese 背景句 / 引用句 / 观点句). When a directory is passed, only `stage1*.json` files in it are read, so `sections.json` can live in the same `labels/` directory. Sentences not covered by any file fall back to the rule prior and are flagged in the report.

### `scores/stage2_NNN.json` (three-dimension scores)

```jsonc
[{"id": 18, "depth": 2, "breadth": 3, "height": 4,      // integers 1-5 (non-integers are rounded with a warning)
  "confidence": "medium",                                  // low | medium | high, optional
  "rationale": "..."}]                                     // <= 60 words, naming the R# compared against
```

The last item per `id` wins. A scored sentence must be labeled `opinion`; otherwise the score is excluded with a warning.

### `labels/sections.json` (section types)

```json
{"2": "analytical", "4": "descriptive"}
```

Keys are section `idx` values (the number in brackets in `sections.txt`; the full section title is also accepted). Values: `descriptive | comparative | analytical`.

### `evidence.json` (evidence; written by `fetch_evidence.py` or by you)

```jsonc
{"4": {"title": "...", "abstract": "...", "year": 2024, "venue": "...", "source": "openalex", "matched": true},
 "7": {"matched": false},
 "9": {"title": "...", "passages": ["paragraph from the cited paper's full text..."], "matched": true}}   // with passages, the 2 passages with the highest lexical overlap are used
```

Keys are reference ids (the same ids as in `references.json` / the `refs` table of `sentences.json`).

## Files generated by the scripts

### `sentences.json`

```jsonc
{
  "source": {"title": "...", "type": "pdf", "pages": 6}, "lang": "en", "citation_style": "numeric",
  "stats": {"sentences": 136, "citing_sentences": 25, "skipped_short": 13, "sections": 19, "references": 27,
            "by_rule": {"context": 99, "citation": 24, "opinion": 13}},
  "warnings": [],
  "sections": [{"idx": 2, "title": "1 Introduction", "level": 1, "sentences": 19, "citing": 1, "ref_ids": [10, 13]}],
  "refs": {"10": {"title": "...", "title_guess": false, "authors": [], "year": 2025, "venue": "", "doi": "", "arxiv": "", "url": "", "raw": "..."}},
  "paragraph_refs": {"7": [10, 13, 18]},                    // paragraph id -> references cited in it (evidence for opinions without a marker)
  "sentences": [{"id": 18, "section_idx": 2, "section": "1 Introduction", "paragraph_id": 7, "page": 1,
                 "text": "...", "prev": "previous sentence", "markers": ["[20, 27]"], "ref_ids": [20, 27],
                 "rule": {"type": "opinion", "strength": "strong", "signals": ["however"]}}]
}
```

Skipped: acknowledgments, references, appendices, ethics statements, figure / table captions, very short or non-text sentences.

### `stage2/plan.json`

```jsonc
{"opinion_total": 13, "selected": 13, "sampled": false,
 "items": [{"id": 18, "scope": "sentence|paragraph|none", "refs": [20, 27], "with_evidence": 2}]}
```

`scope`: evidence comes from the sentence's own citations / from other sentences' citations in the same paragraph / none. `with_evidence`: how many of those references have abstract or full-text evidence.

### `insight_report.json`

| Key | Content |
| --- | --- |
| `config` | weights, level thresholds, top_k |
| `sentence_types` | total, counts and ratios per type, citing sentences, unlabeled sentences |
| `overall` | number scored, mean composite, level, profile (`depth/breadth/height/balanced`) |
| `dimensions` | `n/mean/median/std/min/max` for the three dimensions and the composite, plus 1–5 histograms |
| `levels` | low / medium / high counts and shares at sentence and section level |
| `dominant` | distribution of the dominant dimension (`depth/breadth/height/mixed/none`) |
| `confidence` | distribution of score confidence |
| `section_types` | descriptive / comparative / analytical counts and shares (typed sections only) |
| `sections[]` | per section: sentences, citing sentences, counts per type, scored, dimension means, composite, level, section type |
| `top[]` `bottom[]` | highest / lowest composite opinion sentences (text, scores, level, rationale); `bottom` is empty when there are at most top_k scored sentences |
| `unscored_opinion_ids` | opinion sentences without a score |
| `caveats` | input warnings, thin evidence, high share of low confidence, sampling, … |
| `sentences[]` | per sentence: type, and for scored ones the scores, composite, level, dominant dimension, confidence, rationale |

### `insight_report.md` / `insight_sentences.csv`

The Markdown report (overview, overall assessment, distributions, section table, top / bottom sentences, caveats) follows the paper's language unless `--lang` is given. The CSV has one row per sentence, encoded `utf-8-sig` so Excel opens it cleanly.
